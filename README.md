# Dr. Fabrício Santos Araújo

Site em React e Vite, com identidade em azul claro e branco gelo inspirada na descrição visual da VM9 Viagens fornecida pelo usuário.

## Executar

```sh
npm install
npm run dev
```

## Gerar versão de produção

```sh
npm run build
npm run preview
```

O conteúdo está em `src/main.jsx` e a estilização em `src/styles.css`. A foto original fornecida está em `public/material-fabricio.jpeg`; os retratos são enquadramentos por CSS dessa mesma imagem.

## Origem do conteúdo

Dados extraídos do dossiê `Dr_Fabricio_Santos_Araujo_completo.zip` fornecido pelo usuário, consolidado em 26/09/2026. A página usa identidade, formação, áreas de atendimento, endereço profissional, telefones e redes sociais desse material. Os convênios listados são os identificados na imagem promocional, com confirmação de cobertura pelo contato da clínica. Os horários não são publicados porque as fontes do pacote divergem. Não foram criados depoimentos, resultados de tratamento ou fotografias adicionais.

Agendamento e consultas de convênio abrem o WhatsApp; não há formulário que armazene dados, backend ou confirmação automática de consulta. A fonte Manrope é carregada pelo Google Fonts, com alternativa sans-serif local. O site respeita a preferência por movimento reduzido.
